默认规则：首次输入开始工作；50 分钟到点自动进入10分钟休息；休息结束解除阻挡并提示记录喝水；等待下一次输入开始新一轮。短暂锁屏暂停工作累计，锁屏/睡眠连续满10分钟可完成自然休息；不把单纯无输入判为休息。

系统边界：普通用户进程不能拦截 Ctrl+Alt+Delete 安全桌面或抗管理员终止。不变更系统密码、策略或电源方案。普通键鼠输入全部拦截（包括注入事件，可能影响 UI 自动化）。紧急解除：Ctrl+Shift+F12 连续8秒。输入钩子独立线程，UI失去心跳自动释放，进程退出自动恢复。

最终验证：21项行为测试通过；Release构建零警告、零错误；两屏真实短时输入拦截测试通过，音乐实际播放和防黑屏释放通过。
